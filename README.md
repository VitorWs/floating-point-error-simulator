# floating-point-error-simulator
Simulador em Java para análise de aritmética de precisão finita, propagação de erros, truncamento, arredondamento simétrico e cancelamento subtrativo.

Projeto desenvolvido no âmbito da unidade curricular de Cálculo Numérico. Consiste num simulador em Java concebido para demonstrar e quantificar o impacto da precisão finita em operações de vírgula flutuante. Através da parametrização de n dígitos significativos na mantissa, a ferramenta permite avaliar os métodos de corte (truncamento e arredondamento simétrico), monitorizar a propagação e acumulação de erros numéricos e evidenciar fenómenos críticos de instabilidade matemática, tais como o cancelamento subtrativo.
